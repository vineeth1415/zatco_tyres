# ZATCO Tyres Corporate Website & Design System

This repository contains the complete corporate website code and design system for **ZATCO Tyres**, synchronized directly from **Google Stitch** (Project ID: `11284974030961138057`).

---

## 🎨 Design System: Industrial Precision

* **Brand Aesthetics:** Modern Industrialism with high-utility precision, structural line accents, and tight 4px soft radius corners.
* **Color Palette:**
  * **Primary (ZATCO Navy Blue):** `#00236f`
  * **Secondary (Performance Red):** `#bb0112`
  * **Tertiary (Steel Slate):** `#1d2b3d`
  * **Surface / Background:** `#f7f9fb`
* **Typography:**
  * **Headlines:** `IBM Plex Sans` (700 Bold / 600 Semi-Bold)
  * **Body Copy:** `Work Sans` (400 Regular / 500 Medium)
  * **Technical Specs & Data:** `Josefin Sans` (500 Monospace)
